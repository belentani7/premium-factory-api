# Politica de seguridad

## Versiones soportadas

Se corrige la ultima version publicada en `main`.

## Como reportar una vulnerabilidad

No abras un issue publico. Usa el aviso privado de GitHub
(Security > Advisories > Report a vulnerability) o escribe al mantenedor.

Incluye: version afectada, pasos para reproducir, impacto e idea de arreglo.
